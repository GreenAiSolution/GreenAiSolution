## What makes this portfolio different

**Every repository here is AI-native.** Each project ships with its own
[Model Context Protocol (MCP)](https://modelcontextprotocol.io) server — a working `mcp-server/` that
exposes the project's data and workflows as tools any AI assistant (Claude, etc.) can plug into. Clone a
repo, run `claude mcp add`, and an AI agent can immediately query and operate the project.

```
repo/
├── mcp-server/        ← stdio MCP server (Node + @modelcontextprotocol/sdk)
│   ├── server.mjs     ← project-specific tools, working against real repo data
│   └── README.md      ← tool docs + setup
├── .mcp.json          ← one-line connect for Claude Code
└── ...
```
